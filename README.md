# Offline Counter

Android-приложение Kerimli Systems для локального подсчёта записей
в прокручиваемом списке и экспорта в Excel.

## Работа приложения

Включите службу через стартовый экран, откройте целевой список и нажмите
«Подсчёт» на плавающей панели. Служба возвращается к началу списка,
собирает записи и устраняет повторы по имени и дате рождения.
Результат содержит общее количество и распределение по полу.

Экспорт появляется после обнаружения данных. Файл сохраняется в
`Загрузки/OfflineCounter` с датой, временем и количеством записей в имени.
Кнопка Excel открывает выбор приложения для просмотра, «Поделиться» —
системное меню передачи сохранённого файла.

Панель поддерживает обе темы, свободное перемещение и привязку вблизи края.
Закрытие заблокировано во время подсчёта. Очистка требует повторного нажатия.

## Конфиденциальность

Служба специальных возможностей читает текст открытого списка и прокручивает
его при запущенном подсчёте. Записи находятся в памяти до очистки,
нового подсчёта или завершения процесса. Экспортированные файлы сохраняются
отдельно. Приложение не имеет доступа к интернету, аналитики и рекламы.
При передаче файла выбранное пользователем приложение получает доступ к нему.

## Разработка

Kotlin, Android Views, JDK 17, Android SDK 35; Android 10 и новее.
Namespace и applicationId: `app.offlinecounter`.

```bash
./gradlew testDebugUnitTest lintDebug assembleDebug
```

- `CountingController` — состояние и последовательность подсчёта.
- `PersonParser` — разбор снимка текста списка.
- `CounterAccessibilityService` — события Android, прокрутка и жизненный цикл.
- `OverlayPanel`, `OverlayPlacement`, `OverlayNotice` — панель и уведомления.
- `ExcelExporter`, `WorkbookBuilder` — сохранение и содержимое XLSX.

Алгоритм ожидает поддерживаемый формат ФИО, пола и даты рождения.
Лимиты прокрутки и недоступность источника показываются как ошибка,
чтобы не выдавать частичный результат за полный.

Подготовка и подпись релиза: [docs/RELEASE.md](docs/RELEASE.md).
