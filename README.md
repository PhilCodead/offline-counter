# Оффлайн-счётчик

Android-приложение для подсчёта записей в открытом списке и экспорта результатов в XLSX. Работает через службу специальных возможностей: читает доступный текст, прокручивает список и показывает результат в плавающей панели.

## Возможности

- Подсчёт записей с исключением повторов по ФИО и дате рождения.
- Общее количество и распределение по полу.
- Экспорт в XLSX; дата, время и количество записей в имени файла.
- Открытие и передача сохранённого файла через системные приложения.
- Перемещаемая панель, светлая и тёмная темы.

Обработка выполняется на устройстве. В приложении нет рекламы, аналитики и сетевых запросов.

## Начало работы

Требуется **Android 10 или новее**. Для открытия результатов нужно приложение с поддержкой XLSX.

1. Установите APK из [Releases](https://github.com/PhilCodead/offline-counter/releases/latest).
2. Откройте приложение и нажмите «Включить Accessibility».
3. В системных настройках выберите «Оффлайн-счётчик» и включите службу.
4. Вернитесь к списку и нажмите «Подсчёт» на плавающей панели.

После обнаружения записей появляются действия экспорта и передачи. Кнопка «В Excel» сохраняет файл в `Загрузки/OfflineCounter` и открывает его. Перед передачей файл необходимо сохранить.

Дополнительная инструкция доступна на стартовом экране. Названия разделов системных настроек зависят от устройства и версии Android.

## Поддерживаемые данные

Распознавание рассчитано на текстовые записи с ФИО, полом и датой рождения в поддерживаемом формате. Приложение читает дерево специальных возможностей; изображения и текст, недоступный через этот интерфейс, не распознаются.

Записи с одинаковыми ФИО и датой рождения учитываются один раз. Регистр и повторяющиеся пробелы в ФИО не влияют на сравнение. Совпадение этих полей у разных людей также приведёт к объединению записей.

Во время подсчёта сохраняйте исходный список открытым. При сообщении о недоступности списка или превышении лимита прокрутки результат следует считать неполным.
