# Участие в разработке

Перед изменением поведения откройте issue с описанием сценария.
Исправления отправляйте через pull request с результатами проверки.

Запуск проверок:

```sh
./gradlew testDebugUnitTest testReleaseUnitTest lintDebug lintRelease assembleRelease
```

Используйте Kotlin и существующие границы компонентов. Не меняйте алгоритм
подсчёта ради косметического рефакторинга. Для ошибки добавьте воспроизводимый
сценарий; интерфейс проверяйте в обеих темах и при крупном системном шрифте.

Не прикладывайте ключи, пароли, APK с неизвестной подписью и реальные списки
с персональными данными. В тестах используйте синтетические записи.

Публичная доступность исходников сама по себе не предоставляет лицензию
на их распространение. Условия использования уточняются у правообладателя.
