# Оффлайн-счётчик 1.0.3

- Исправлен подсчёт записей в варианте списка «Принятые» при прокрутке.

Требуется Android 10 или новее. APK подписан постоянным ключом Kerimli Systems для обновления версии 1.0.2.

Проверки выпуска: по 52 модульных теста debug и release без ошибок, Android Lint, сборка release APK и проверка подписи. Проверка на физическом устройстве не выполнялась.
