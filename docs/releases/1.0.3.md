# Оффлайн-счётчик 1.0.3

- Исправлен подсчёт записей в варианте списка «Принятые» при прокрутке.
- В XLSX первые записи теперь расположены сразу под заголовками; общее количество и распределение по полу находятся в F1–F3.

Требуется Android 10 или новее. APK должен быть подписан постоянным ключом Kerimli Systems для обновления версии 1.0.2.

Проверки выпуска: модульные тесты debug и release, Android Lint, сборка release APK и проверка подписи. Проверка на физическом устройстве ожидает подтверждения после установки сборки.
