# Оффлайн-счётчик 1.0.1

Исправление отображения иконки в лаунчере и на системном экране запуска.

## Изменения

Иконка использует векторные слои. Удалены светлая кайма по краю и двойная скруглённая подложка. Поведение подсчёта и экспорта не изменено.

## Установка

Требуется Android 10 или новее. Загрузите `Offline-Counter-1.0.1-release.apk` из раздела Assets.

Релиз подписан тем же сертификатом, что и 1.0.0, и поддерживает установку поверх него. Debug-сборки используют другой сертификат; перед переходом сохраните нужные результаты вне приложения.

| Параметр | Значение |
| --- | --- |
| Пакет | `app.offlinecounter` |
| Версия | `1.0.1` |
| versionCode | `22` |
