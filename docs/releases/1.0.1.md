# Оффлайн-счётчик 1.0.1

Первый публичный выпуск Оффлайн-счётчика от Kerimli Systems — приложения для подсчёта записей в открытом списке и экспорта результатов в XLSX.

## Возможности

- Подсчёт через службу специальных возможностей с исключением повторов по ФИО и дате рождения.
- Общее количество записей и распределение по полу.
- Перемещаемая плавающая панель, светлая и тёмная темы.
- Экспорт в XLSX с датой, временем и количеством записей в имени файла.
- Открытие и передача сохранённого файла.
- Локальная обработка данных без сетевых запросов.

## Установка

Требуется Android 10 или новее. Загрузите `Offline-Counter-1.0.1-release.apk` из раздела Assets.

APK подписан сертификатом Kerimli Systems. После установки откройте приложение и включите службу специальных возможностей, следуя встроенной инструкции.

| Параметр | Значение |
| --- | --- |
| Пакет | `app.offlinecounter` |
| Версия | `1.0.1` |
| versionCode | `22` |
