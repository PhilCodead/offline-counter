# Обновление сборочного окружения

Выпуск 1.0.2 сохраняет проверенное сочетание AGP 8.13.2, Gradle 8.13 и Kotlin 2.3.0.

## Отложенные обновления

- AndroidX Core 1.19.0 требует compileSdk 37 и AGP 9.1.0 или новее. Проверка метаданных зависимостей в [PR #13](https://github.com/PhilCodead/offline-counter/pull/13) завершается ошибкой на текущем окружении.
- Kotlin 2.4.20 отложен до согласованного обновления AGP/R8. Обоснование совместимости сохранено в [PR #8](https://github.com/PhilCodead/offline-counter/pull/8).

Исключения Dependabot ограничены указанными версиями; остальные обновления продолжают проверяться. При переходе на новый инструментарий удалите соответствующие исключения, обновите SDK в CI и документации, выполните тесты обеих конфигураций, lint и проверку подписанного APK на устройстве.
