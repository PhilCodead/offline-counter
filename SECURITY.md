# Безопасность

Поддерживается последняя опубликованная release-версия.
Приложение работает локально и не запрашивает разрешение INTERNET.

Не публикуйте персональные данные или рабочий эксплойт в обычном issue.
Используйте вкладку Security → Report a vulnerability, если она доступна.
Если приватный канал отключён, создайте issue только с просьбой предоставить
канал связи, без технических подробностей и конфиденциальных вложений.

Ключ подписи хранится отдельно от репозитория. Проверяйте APK и SHA-256
в GitHub Releases. Инструкции по выпуску находятся в docs/RELEASE.md.
