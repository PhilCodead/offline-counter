# История изменений

## Не выпущено — 1.0.2

### Изменено

- Compile SDK обновлён до 36.1, target SDK — до 36, Build Tools — до 36.0.0.
- Обновлены AGP до 8.13.2, Gradle до 8.13 и Kotlin до 2.3.0.
- Обновлены AndroidX Core до 1.18.0, AppCompat до 1.7.1 и Material до 1.13.0.
- Robolectric обновлён до 4.17; проверки панели выполняются на API 29, 35 и 36.

### Исправлено

- Стартовый экран учитывает отступы системных панелей и вырезов при отображении edge-to-edge на Android 16.

## [1.0.1](https://github.com/PhilCodead/offline-counter/releases/tag/v1.0.1) — 2026-09-19

### Исправлено

- Удалены светлая кайма и двойная подложка иконки на системном экране запуска.
- Иконка переведена на векторные слои для согласованного отображения в лаунчере и на экране запуска.

## 1.0.0 — 2026-09-19

Первый релиз с постоянным сертификатом подписи Kerimli Systems.

- Подсчёт записей через службу специальных возможностей с исключением повторов.
- Плавающая панель со светлой и тёмной темами.
- Экспорт в XLSX с датой, временем и количеством записей в имени файла.
- Открытие и передача сохранённого файла.
- Блокировка закрытия панели во время подсчёта и подтверждение очистки.
