# 0.14

- Namespace сохранён как `app.offlinecounter`.
- Добавлены воспроизводимая Gradle-сборка и GitHub Actions.
- Усилены парсер, границы прокрутки и ограничение циклов подсчёта.
- Генерация XLSX вынесена в тестируемый компонент.
- Обновлены стартовый экран и плавающая панель в стиле One UI.
- Убрано системное размытие приложения под плавающей панелью; сохранены привязка к краю и положение панели.
- Повышена контрастность единой подложки панели, без отдельной полоски в свёрнутом состоянии.
- Закрытие панели выполняется с первого нажатия; подтверждение сохранено только для очистки результатов.
- Завершение подсчёта, сохранение, ошибки экспорта и подсказка перед отправкой показываются через Toast.
- Добавлена раскрывающаяся инструкция и прямой переход к экрану включения службы специальных возможностей.
- Иконка полностью заменена на синюю контактную карточку с бейджем «12»; добавлены адаптивный и монохромный варианты.
- Добавлены логотип Kerimli Systems и автоматическое отображение версии.
- Подтверждено отсутствие сетевого разрешения и сетевых библиотек.
